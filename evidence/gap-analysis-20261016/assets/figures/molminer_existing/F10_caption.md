# Figure caption

**Figure: PolyGen C1 versus MolMiner under matched target/sample budgets.** (A) Mean absolute error to the requested log10 conductivity target under the frozen PolyGen random-forest verifier. (B) Strict target-hit rate using the existing C1 tolerance rule. (C) Mean verifier prediction versus requested target; the dashed line is ideal calibration. (D) MolMiner-native growth profile, showing median fragment steps and median heavy atoms; these are not token-equivalent to PolyGen sequence length. PolyGen values are means across five training seeds. MolMiner values are from one released `best_polyru_s42.pth` checkpoint sampled with five seeds. The checkpoint was trained on the merged released corpus, which includes HTP-MD, so the comparison is a matched-budget behavioral baseline rather than a held-out performance claim.
