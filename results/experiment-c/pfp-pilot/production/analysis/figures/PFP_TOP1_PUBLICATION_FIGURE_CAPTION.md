# Figure caption: PFP top-1 pilot validation

**Figure.** Paired PFP/HTP-MD validation of one continuous-value and one binary
PolyGen top-1 polymer-electrolyte candidate. **(A)** RF-proxy conductivity and
PFP cluster Nernst–Einstein (cNE) conductivity for the same candidate in each
arm; vertical segments are paired candidate-wise differences and the displayed
residuals are PFP minus proxy in log10(S cm−1). **(B)** Li+ and TFSI−
diffusivities from the final 160 ps of each 200 ps trajectory after a 40 ps
discard. **(C)** cNE conductivity recomputed over cumulative analysis windows;
the dashed line marks the predeclared 40 ps discard. Each arm contains one
matched candidate and one replica, so no uncertainty interval or inferential
test is shown. Both trajectories pass the technical evidence gates, but the
window drift supports the label `NON_CONVERGED_SMOKE_ONLY`; the figure is a
workflow-validation result and does not establish converged model superiority
or experimental accuracy.
