# Full-atom MD handoff (not executed in this local run)

The paper's final validation is not the RF diagnostic. For every row in `md_candidate_manifest.csv`, build a linear homopolymer with at least 150 backbone heavy atoms, then create a polymer/LiTFSI system at 1.5 mol kg-1. Use PCFF+ and LAMMPS. Generate an amorphous starting structure, relax it, run sequential NVT and NPT equilibration until the density is stable, then run NVT production at 353 K for 5 ns with a 2 fs step (2,500,000 steps). Run five independently initialized replicas per candidate. Compute ionic conductivity with the same cluster Nernst-Einstein trajectory-analysis implementation used for HTP-MD.

Acceptance and reporting: retain every attempted replica; distinguish force-field-parameter absence from unstable temperature/pressure/configuration; require at least one successful production trajectory to report a candidate and report the distribution across successful replicas. Compare candidate means/distributions to the HTP-MD best value under the same protocol, 5.07e-4 S/cm. Do not label candidates experimentally validated. The paper itself notes that 5 ns may be insufficient for slow transport and points to 50 ns as more reliable.

Public-release gap: `Example-simulation-files/` contains an equilibrated example system and production input, but the release does not provide a turnkey p-SMILES-to-amorphous-system builder, complete arbitrary-polymer PCFF+ parameterization, the publication GNN checkpoint, or all trajectory-analysis machinery needed to run these new structures locally. Therefore the manifest is a queue for the original HTP-MD/MD environment, not evidence that MD has completed.
