# Go / no-go — which uncertainty should the next budget remove?

No row below is automatic execution authorization. Reviewer acceptance, an assigned analyst and a scoped resource allocation precede the proposed R1 fits. New physical work has additional protocol/parameterization gates. All thresholds are prospective **design proposals**, not post-hoc acceptance of existing results.
