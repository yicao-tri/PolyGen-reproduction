# PolyGen paper work

For new polymer-generation paper results, follow `registry/paper/README.md`: preserve immutable sources and register the result, units, conditions, independent unit, evidence tier and uncertainty/missingness through `registry/paper/progress.py record`. Include the versioned input and rebuilt SQL receipt in the result PR. The historical evidence database remains unchanged.

Stage-1 design delivery, scientific execution, and human sign-off are separate states. Do not mark science complete because design documents or software tests pass. Keep other chats' outputs, frozen scientific data and submission-root manuscripts untouched unless the user explicitly requests their modification.
